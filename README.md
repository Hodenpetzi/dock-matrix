# Handheld Dock Matrix

A sourced, dated compatibility matrix for docks used with PC gaming handhelds (ROG Xbox Ally / Ally X, Lenovo Legion Go 2, Steam Deck LCD and OLED).

Live site: https://hodenpetzi.github.io/dock-matrix/

This project does not run its own hardware tests. Every compatibility, resolution, VRR or power-delivery figure is attributed to a named manufacturer or dated public source. Official sources that disagree are left visible.

The site is static HTML and CSS, with a short inline script for table filtering. There is no tracking, no analytics, and no live affiliate IDs.

Pico CSS v2.1.1 (MIT) is bundled in `assets/vendor/pico/`. Device and dock drawings are original inline SVGs, not manufacturer product photos.

This repository contains only the public site. Working notes and preview screenshots are kept elsewhere.
